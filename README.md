# راهنمای کامل قالب وردپرس تامین پلاسما نوژین (Tamin Theme)

![پوسته تامین پلاسما نوژین](screenshot.png)

**نسخه:** ۱.۰.۰  
**سازگاری:** وردپرس نسخه ۶.۴+ و PHP نسخه ۸.۱+  
**توسعه‌یافته با:** Tailwind CSS v3، JavaScript ES6، فونت اختصاصی پیدا، Swiper و FontAwesome  

---

## 📋 معرفی پوسته

پوسته **تامین پلاسما نوژین** یک قالب کاملاً پویا، مدرن، واکنش‌گرا و بهینه‌سازی‌شده برای مراکز اهدای پلاسما و موسسات پزشکی و درمانی است. این قالب بر اساس استانداردهای رسمی مهندسی وردپرس پیاده‌سازی شده و امکان مدیریت ۱۰۰٪ محتوا، لینک‌ها، متون هدر و فوتر، رنگ‌بندی برندینگ و فرم‌های نوبت‌دهی را از پیشخوان وردپرس فراهم می‌سازد.

---

## 🚀 ویژگی‌های کلیدی پوسته

1. **سازگاری ۱۰۰٪ با ظاهر و ساختار اولیه:** حفظ کامل چیدمان، انیمیشن‌ها، پالت رنگی و DOM دسکتاپ و موبایل.
2. **سفارشی‌ساز آکاردئونی وردپرس (Customizer API):** مدیریت زنده متون اعلان، تلفن پشتیبانی، ساعات کاری، آدرس، لینک شبکه‌های اجتماعی، پالت رنگ‌های اصلی برند و تمام لینک‌های دکمه‌ها.
3. **سیستم متاباکس پیشرفته برگه‌ها (`includes/page-metaboxes.php`):** تب‌های سفارشی برای مدیریت هدر/هیرو برگه‌ها و تنظیمات اختصاصی هر برگه در صفحه ویرایش همان برگه.
4. **فرم‌های تعاملی AJAX با امنیت بالا (`includes/forms.php`):**
   - **فرم ثبت نوبت اهدای پلاسما:** نوبت‌دهی چندمرحله‌ای، اعتبارسنجی Nonce، محدودیت ارسال (Rate Limiting ۶۰ ثانیه‌ای بر اساس IP) و **تولید خودکار کد پیگیری اختصاصی** (مانند `NOZHIN-100200`).
   - **فرم تماس با ما و مشاوره:** ارسال تعاملی بدون ریلود صفحه با نمایش باکس‌های پیام موفقیت/خطا.
5. **بارگذاری ۱۰۰٪ محلی دارایی‌ها (Zero External CDNs):** بارگذاری بومی فونت پیدا (Peyda WebFont)، اسکریپت Swiper و آیکون‌های FontAwesome بدون وابستگی به شبکه خارجی.
6. **معماری ماژولار PHP:** تفکیک کدها در پوشه `includes/` شامل `setup.php`, `enqueue.php`, `helpers.php`, `security.php`, `sidebars.php`, `customizer.php`, `page-metaboxes.php` و `forms.php`.
7. **پشتیبانی کامل از RTL و Accessibility:** رعایت استانداردهای دسترسی‌پذیری وب و ساختار HTML5.

## 📁 ساختار پوشه‌ها و فایل‌های پوسته

```text
tamin-theme/
├── assets/                  # دارایی‌های ایستا تم
│   ├── css/
│   │   ├── fontawesome.min.css
│   │   ├── swiper-bundle.min.css
│   │   └── tailwind.css     # CSS نهایی تولیدشده توسط Tailwind CLI
│   ├── fonts/               # فونت وب پیدا (WOFF & WOFF2)
│   ├── images/              # تمامی آیکون‌ها و تصاویر قالب
│   └── js/
│       ├── main.js          # اسکریپت تعاملی کلاینت (Swiper, Modal, Animations)
│       └── swiper-bundle.min.js
├── includes/                # هسته منطق تم
│   ├── customizer.php       # پنل آکاردئونی سفارشی‌ساز وردپرس
│   ├── enqueue.php          # مدیریت Enqueue بومی استایل‌ها و اسکریپت‌ها
│   ├── forms.php            # هندلرهای AJAX فرم‌ها، Nonce و Rate Limiting
│   ├── helpers.php          # توابع کمک‌کننده و محاسبه‌گر لینک‌های پویا
│   ├── page-metaboxes.php   # سیستم متاباکس اختصاصی برگه‌ها
│   ├── security.php         # توابع ایمن‌سازی و Sanitize
│   ├── setup.php            # ثبت قابلیت‌های تم، منوها و بذرپاشی خودکار
│   └── sidebars.php         # ثبت نواحی ویجت‌خور و نوار کناری
├── template-parts/          # کامپوننت‌ها و قطعات پویا
│   ├── front-page/          # کامپوننت‌های صفحه اصلی (hero, about, conditions,...)
│   └── post/                # کامپوننت کارت نوشته (content-card.php)
├── archive.php              # قالب آرشیو اخبار و وبلاگ
├── footer.php               # فوتر وردپرسی پویا
├── front-page.php           # قالب صفحه اصلی پویا
├── functions.php            # فایل اصلی بارگذاری تم
├── header.php               # هدر وردپرسی پویا
├── home.php                 # خانه وبلاگ
├── page.php                 # قالب عمومی برگه‌ها
├── page-about.php           # قالب اختصاصی درباره ما
├── page-contact.php         # قالب اختصاصی تماس با ما
├── page-plasma-info.php     # قالب اختصاصی اهدای پلاسما
├── page-policy.php          # قالب اختصاصی خط مشی
├── page-request.php         # قالب اختصاصی نوبت‌دهی اهدا
├── page-units.php           # قالب اختصاصی شعب و واحدها
├── single.php               # نمای تک نوشته (سینگل)
├── style.css                # هدر اصلی معرفی پوسته به وردپرس
└── README.md                # مستندات راهنمای تم
```

## 🛠️ دستورات توسعه و Build استایل‌ها

این تم از **Tailwind CSS CLI** و **Vite** جهت کمپایل CSS محلی استفاده می‌کند.

```bash
# نصب وابستگی‌ها
npm install

# اجرای حالت توسعه (Development Mode با Hot Reload)
npm run dev

# تولید خروجی نهایی ساختاری (Production Build)
npm run build
```

## 🔒 استانداردهای امنیت و کارکرد

- تمامی فایل‌های قالب شامل دستور بررسی `defined('ABSPATH') || exit;` می‌باشند.
- تمام ورودی‌های کاربر از طریق توابع `sanitize_text_field`, `sanitize_email` و `sanitize_textarea_field` ایمن‌سازی شده‌اند.
- تمامی خروجی‌های متنی با توابع `esc_html`, `esc_attr`, `esc_url` و `wp_kses_post` خروج‌یابی (Escape) می‌شوند.
- ارسال فرم‌ها نیازمند نانس امنیتی وردپرس (`wp_nonce_field`) بوده و با مکانیزم Rate Limiting مانع از ارسال اسپم می‌گردد.
